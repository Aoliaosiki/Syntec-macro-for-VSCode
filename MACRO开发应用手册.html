前言

为增加控制器应用弹性，新代控制器提供MACRO程序编辑功能。

当加工程序被宣告成MACRO格式后，该档案将如同一般程序语言，可使用特定数学函数，如此一来，除了原本即有的移动和补偿指令功能，更拥有逻辑判断及数学演算功能。

档案格式

程序内容第一行需使用"%"宣告为标题行，并加入关键字"@MACRO"，才会被视为 MACRO 格式档处理。否则该档案将被视为ISO格式档处理。

不支援 MACRO 语法使用
(有部分 MACRO 语法无法被正确解读，可能会跳出"COM-003 控制器解译宏程序时发现程序句法有误"的警报)

可以使用 MACRO 语法的完整功能。

每一行结尾加或不加分号";"皆可。

1. 除了特定语法外(请参考语法说明内容)，每一行结尾都要加上分号";"。

2. 10.120.45 前，如未加分号，会和下一行合并处理。若没有检查出警报，仍会正常执行。
3. 10.120.45 后，除了特定语法外，该行没有加上分号时，会跳出 COM-008【子句中没有结束的符号' ; '】。
4. 10.120.61 后，如未加分号，会和下一行合并处理。若没有检查出警报，仍会正常执行。

范例：

使用到"( ... )"，刮号内的内容...，会视为注解省略。

使用到"(* ... *)"，刮号内的内容...，会视为注解省略。

依照 PR3201 车床程序所设定的操作习惯书写。

只能以车床习惯C-type书写。

备注：

  1. 被当作副程序（子程序）或宏程序呼叫的加工档，建议不要使用多轴群档案（含轴群辨识符号$1、$2）。
    若有此应用情境，多轴群副程序档案必须小于60KB(60000bytes)，否则控制器将报警COR-203 加工程序格式不符；单轴群副程序则不在此限。

  2. 不支援MACRO格式的多轴群（含轴群辨识符号$1、$2）的副程序。

  3. 档案若超过60KB(60000bytes)

    1. 10.120.32及其以后的软件版本：支援IF、CASE、REPEAT、FOR、WHILE等等有范围区间的语法。

      1. 执行加工前建议执行图形模拟进行语法检查。

      2. 语法范围区间过大时，在加工时有可能会使轴向降速。可查看诊断变数D320「解译总线单节数」及D376「运动规划减速次数」来判断是否为语法范围区间过大造成轴向降速。

        代码区块

        %@MACRO

G01 X30. Y30.;

#1 := 1;
IF #1 = 2 THEN

// ===================
// IF条件不成立
// 此处加工程序不执行
// ===================

END_IF;

G01 X100. Y100.;	// 执行此行前，轴向可能产生降速

    2. 10.120.32之前的软件版本：无法支援IF、CASE、REPEAT、FOR、WHILE等等有范围区间的语法，否则会报警COR-204 档案太大。

  4. 除了程序注解、使用字串做为引数的Macro语法以外，仅允许以ASCII撰写加工程序。若使用者在加工程序中撰写了ASCII以外的字符，将会跳警报COM-027 无效的字符。

  5. 支援 CR ("\r")、LF ("\n")、CR LF ( "\r\n" ) 三种换行方式。

备注：

  1. 其余未说明之指令格式由相关G码以引数形式带入

  2. 一般在副程序中会使用"GETARG"函数来读取引数内容，而在主程序（父程序）中可使用之引数形式规则如下：

    1. 使用引数D、E、H、I、J、K、L、M、P、Q、R、T，仅能使用单一符号传入引数，例如「G101 X30. Y40. D50. ;」，若在其后附带数字将引发警报，例如「G101 X30. Y40. D1=50. ;」

    2. 使用引数A、B、C、F、S、U、V、W、X、Y、Z，除了使用单一符号传入引数，亦可在其后附带数字，例如「G101 X30. Y40. Z1=50. ;」

    3. 使用引数时，若在同一单节下复数个相同的引数，解译时会使用最后一个引数值来执行。
      例如:

      // 范例一，引数直接为轴向情形
G00 X10. X100.;  // 此时实际执行G00 X100.
G01 X20. X-100.; // 此时实际执行G01 X-100.


// 范例二，引数会被带入G码或Macro
G02 X60. C50. I-30 I20 J60 // 此时实际执行G02 X60. C50 I20 J60
G100 A10. B20. B50. C20.;  // 此时实际执行G100 A10. B50. C20.

// 范例三，功能G码
G10 L1000 L1500 P1 P2 Q1; // 此时实际执行G10 L1500 P2 Q1

    4. 使用引数亦可在其后进行数值或存值为数值之变数运算，运算式的括号可省略。
      例如:

      #1 := 3.0;

G01 X(1.0+3.0) // 数值运算，执行的结果为G01 X4.0
G01 X(4.0*#1)  // 存值为数值之变数运算，执行的结果为G01 X12.0
G01 X30.0/2.0  // 运算式的括号可省略，执行的结果为G01 X15.0

    5. 以上所有动作指令之后，仅可使用数值或存值为数值之变数，否则可能因程序解译之编码限制而造成系统错误，此误用情况不在控制器的保护范围内。

变数指定

变数指定

语法

<变数> := <叙述>;

说明

指定变数内容

范例一

直接定值

@1 := 123;
#1 := 456;

AR1 := 789;		// App 区域变数
MAR1 := 789;	// App 永久储存变数

#10 := "12";	// 区域变数#10内容为12
@10 := "12";	// 公用变数@10内容为12849

范例二

间接定值

#1:= 123;
		
@[#1] := 567;		// @123=567
@[#1+7]:=890;		// @130=890

AR[#1] := 789;		// AR123=789
MAR[#1] := 789;		// MAR123=789

备注

  1. 范例一中的"12"为字串写法，表示要将字串存入变数中，只有存入公用变数时，控制器会先进行ASCII转码，区域变数则不会。

  2. 承上，欲正确读取公用变数所储存的字串内容，请使用SCANTEXT函数。

  3. 范例二中请留意用的是"中刮号"

  4. App变数(AR、MAR)使用限制：

    1. 支援版本：10.118.39及之后版本。

    2. 只有APP专用的Macro才支援存取AR、MAR。若在其他加工程序呼叫，则跳警报COR-016。

    3. 若欲存取的变数超出范围，例如只有512个MAR却下MAR512 := 1;，则跳警报COR-016。(AR、MAR变数号码为0-Based)

    4. 直接存取负的变数位址，例如MAR-1 := 1;，则跳警报COM-003。

    5. 直接存取小数的变数位址，例如MAR1.1 := 1;，则跳警报COM-003。

    6. 间接存取负的变数位址，例如MAR[-1] := 1;，则跳警报COR-016。

    7. 间接存取小数的变数位址，例如MAR[1.1] := 1;，则跳警报COR-016。

    8. AR、MAR皆不支援存字串。

    9. 仅支援Macro格式，不支援ISO格式。

GOTO

GOTO

语法

GOTO n;

说明

此语法需配合单节次序码使用，可跳到指定的N行号执行其内容，假设程序中同时存在两个N行号，则以该程序中第一个N行号为准。

范例

%@MACRO
#1 := 1;
#2 := 10;
IF #1 = 1 THEN

GOTO #2;

END_IF;

IF#1 = 2 THEN

GOTO 100;

END_IF;

N10;

G01 G90 X50. Y0. F1000;

M30;

N100;

G01 G90 X0. Y50. F1000;

M30;

备注

使用REPEAT/WHILE/FOR/GOTO等回圈功能时，应谨慎注意无穷回圈问题，当此问题发生时，会造成人机画面锁死或加工程序卡死。

建议在回圈中适时加入SLEEP()函数，若不小心进入无穷回圈，仍有机会操作人机画面以中止程序执行。

CASE

语法

CASE <条件变数> OF
<变数>:
    <陈述列表>
<变数>,<变数>:
    <陈述列表>
<变数>,<变数>,<变数>:
    <陈述列表> 
ELSE
    <陈述列表>
END_CASE;

说明

多条件判断，根据条件变数内容，分别执行不同程序区块。请注意"变数"内容需为大于等于0之整数型态。

范例

%@MACRO
#1 := 1;
G01 G90 X0. Y0. F1000;
CASE #1 OF
1:
    X(1.0*#1) Y(1.0*#1);..
2:
    X(2.0*#1) Y(2.0*#1);..
3, 4, 5:
    X(3.0*#1) Y(3.0*#1);..
ELSE
    X(4.0*#1) Y(4.0*#1);..
END_CASE;
M30;

备注

  •  结尾符号可写END_CASE或ENDCASE

  • 当未加 END_CASE; 时，将报 COM-023【CASE宏程序子句找不到' ELSE '或' END_CASE '】或 COM-024【CASE宏程序子句找不到' END_CASE '】

IF

说明

IF条件判断

范例

%@MACRO
#1 := 3.0;

MSG规格说明

  • MACRO警报发生时，必须复位系统才可消除警报；而MSG自订提示仅需按下"ESC"即可消除，可用于单纯提示状态，但须注意当程序结束时，提示也会自动消失。

  • 提示内容有字串长度限制，中文 : 19个字，英文 : 39个字。

  • 提示ID只允许使用0~65535之间的整数，否则跳警报COR-023【语意错误】。

  • MSG( -1 ); // 使用负数ID，跳警报COR-023

  • MSG( 100000 ); // 使用ID大于65535，跳警报COR-023
